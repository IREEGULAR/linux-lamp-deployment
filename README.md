# Local LAMP Deployment on Red Hat Linux

## Overview
This project documents my work deploying an instructor-provided PHP web application and database on a local Red Hat Linux server for coursework and practice.

## Technologies
- Red Hat Linux
- Apache HTTP Server
- PHP
- MySQL/MariaDB

## My Contribution
- Placed the provided application files in the server’s web directory.
- Configured PHP database connection settings for my local environment.
- Used the supplied database with the application.
- Made the website accessible through the server’s IP address and port.

## Project Documentation
This repository focuses on my deployment steps, configuration explanations, and troubleshooting notes. Any configuration examples use placeholders instead of real credentials.

## Attribution
The original application code and database were provided by my instructor for private educational use. I did not develop the application or design the database, and those restricted files are not included in this repository.

## Skills Practiced
- Linux web-server configuration
- Local PHP application deployment
- Database connection configuration
- Technical troubleshooting and documentation
